# 野人每日解套

入口：个股分析 → 跟踪与持仓 → 野人每日解套。Hash路由直达链接为
`/#/short-term-strategy/stock-analysis?tab=wildman`。

页面读取现有 `execution.plan`，不再将 `latest_analysis` 日线快照当作当天操作单。
线上 `run_unwind_execution_loop` 已接入组合调度器：交易日北京时间09:00起运行，
用上一交易日完整日线创建按股票、交易日保存的当天预案，网页关闭也会生成。
2026-10-16核验13只持仓均于09:00:40生成当天预案，日线依据为10月15日。
缺少数据时后台重试，非交易日不开新操作单，收市后不会把旧计划改称下一日计划。

方法来自系统内已复核的全能的野人完整讲解：下跌时先卖后低位接回；修复时停止
机械卖出，回到成本线分批退出。3/16、ATR、底仓、费用、连续两次报价确认和时段过滤
是系统增加的保护规则，界面明确区分这两部分。

每日操作单区分卖点候选、已卖待接、修复退出、等待反弹和暂停策略。ST/退市标识、
支撑破位、非正净价差、整手或资金不足都会暂停；一手仓保留更严格的原系统条件。
每张卡先显示当前动作、当前可复核股数与限价，再显示带触发条件的具体步骤。
“今日计划数量”和“当前可复核数量”分开；报价或条件未通过时，后者为0。
已有卖出记录时，接回价和数量使用后台按真实成交重算的目标，并检查整手、
真实资金池和估算最低费用。新成交晚于最近信号检查时，必须重新核验。
预估降本随实际可滚动股数等比例缩减，不将候选计划记成实际成交或收益。

日期按北京时间处理，分别突出适用日期、生成时间、日线依据和盘中报价时间。
早盘计划不会因为生成超过15分钟失效；盘中报价超过120秒暂停当前动作，保留当天预案。
旧日计划、持仓基准变化、未核验的新成交及后台标记失效的计划暂停使用。
后台用间隔45—180秒的连续两次有效报价确认方向，最终可卖数量和费用须核对券商。

应用公共层在登录后挂载唯一的 `GlobalPriceMonitor`，先检查一次，之后每10分钟刷新
`execution/refresh` 并读取新计划和报价。显示开关、上次和下次检查时间及失败状态。
有效期内触达候选卖区或真实卖出后的接回目标时弹窗；野人页已暂停的计划不提醒。
兼容A股数字时间戳和港股斜杠日期，休市、失效、过期行情或刷新失败不发到价提醒。
同股、同日、同方向、同目标价去重，按登录用户隔离会话记录与监控开关。
任意系统页面均可触发高优先级弹窗；路由切换和页面加载不重启计时器，页面面板只订阅全局状态。
提醒覆盖普通弹窗、抽屉及加载层，背景点击和Escape不关闭提醒，仍可明确点击关闭或确认。
全屏时挂载到全屏容器，避免被全屏页面遮住。右下角的“解套提醒”可在任何页面打开控制面板。
关闭系统网页或退出登录才停止；恢复前台且已到检查时间时补查。10分钟抽查可能漏掉中间短暂触价。

刷新失败隐藏旧操作卡片；复制操作单包含日期、当前动作、报价时间、执行前条件和取消条件。原每日分析
与成交账本保持在解套跟踪，最近10次每日判断可从新tab查看。

验证：`tests/wildman-daily-guide.test.ts`覆盖早盘计划、报价过期、跨日、整手、费后资金池、
ST、支撑破位、修复退出、真实接回目标和成交后重算；`unwind-price-monitor.test.tsx`
覆盖定时、暂停、去重、失败重试、跨页面持续、弹窗层级、用户切换与港股时间格式；工作台测试覆盖两个栏目切换。
