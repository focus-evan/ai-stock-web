这四套框架不能混成一个“大杂烩评分”。正确顺序是：先用点火判断市场热度和扩散阶段，再用V2.3.1判断公司是否是更好的可投资表达，再用S五维做数据底稿和横向减法，最后用S40科技成长版判断它是否满足“真赛道、真技术、真客户、真财务、真估值、真能力圈”。

V2.3.1 五层六维择优框架

核心问题不是“谁最正宗”，而是“谁控制利润池、存在预期差、能被资本持续定价，并且经营数据能支撑这个故事”。

1. 五层决策结构

  1. 风险门：先看一票否决、重大风险、交易警示、治理/流动性问题。
  2. 战略优先护城河：卡脖子/国产替代位置，竞争对手与护城河。
  3. 新战略业务：未来布局是否能重构利润池、TAM、护城河和估值上限。
  4. S五维验证：成长、盈利、规模、效率、估值是否支撑叙事。
  5. 六维证据评分：行业、竞争力、财务、估值赔率、催化影子、治理流动性。
  6. 概率与赔率：乐观、中性、悲观情景；好公司也可能不是好买点。
  7. 组合预算：行业、主题、客户链、宏观变量暴露。
  8. 执行复盘：买入、卖出、止损、复盘日期、失效条件。

2. 必做：卡脖子 / 国产替代优先级

必须回答检查内容硬上限
卡脖子环节设备、材料、零部件、芯片、软件、工艺、数据、系统集成。说不清环节，不给战略溢价。
海外对标明确海外公司/产品，说明谁控制高端利润池。海外对标不清，分数不超过13。
替代必要性安全、成本、交付、客户国产化、制裁风险、性能升级。仅政策标签，不进入核心利润池。
替代阶段概念、样品、认证、小批量、量产、收入转化、利润转化。无客户认证或订单，分数不超过12。
替代壁垒技术、良率、可靠性、认证、产能、成本、IP、生态、切换成本。低端替代且高端被海外控制，通常不超过14。
证据强度公告、客户认证、订单、收入拆分、毛利率、进口替代比例。收入/利润粒度不可用，标“能力证据”。
分数含义处理
18-20高端瓶颈清晰，海外对标明确，收入和利润转化可见。战略重估溢价。
14-17真实国产替代，有认证或批量订单，但利润转化早期。观察池溢价。
9-13能力或样品证据存在，但客户/收入证明不完整。催化剂，限制置信度。
4-8主要是叙事或政策标签。题材交易。
0-3不是瓶颈或不是替代海外核心利润池。无国产替代溢价。

3. 必做：竞争对手与护城河

模块必须写清判断标准
国内竞争对手2-5个同链条或同产品对手。不能只说“行业领先”。
海外竞争对手海外基准或替代品。用于确定利润池上限和技术差距。
我有你没有独特产品、资质、工艺、良率、客户、产能、成本、数据、生态、牌照。A级护城河需要硬客户和财务验证。
你有我更强共同能力上，公司在规模、毛利、良率、交付、客户覆盖、成本或迭代更强。B级护城河可给候选/观察溢价。
我弱于你技术、客户、规模、成本、财务、全球渠道上的弱点。必须写，不写就是选择性乐观。
财务验证毛利率、净利率、ROE/ROIC、现金流、应收、存货、客户稳定性。没有财务验证的护城河只是“声称的护城河”。

4. 新战略业务 / 未来布局

目的有两个：不要错过公司下一条估值重构曲线，也不要把没有验证的未来业务当成当前利润支撑。

证据阶段能提高什么不能做什么
概念 / 研发 / 路线图提高关注度，作为未来期权。不能提高财务质量分。
样品 / 客户验证提高催化、影子逻辑和估值上限讨论。没有订单时通常模块分不超过13。
小批量 / 订单提高新业务期权和预期差。利润未转化时不能当业绩锚。
收入 / 利润转化可以进入利润池、财务质量、估值重估。仍需验证毛利、现金流和持续性。

5. 最近四个单季度财务表

累计口径拆单季： Q1 = Q1累计 Q2 = H1累计 - Q1累计 Q3 = Q1-Q3累计 - H1累计 Q4 = FY累计 - Q1-Q3累计
字段用途判读
单季度营收验证需求和规模趋势。硬科技订单、交付变化通常先体现在收入。
归母净利验证利润释放。利润增长超过收入增长，可能效率改善；反之警惕低质量增长。
扣非净利剔除非经常性噪声。归母强但扣非弱，不能升核心。
毛利率判断护城河、价格权、成本压力。高毛利要查产品结构、会计、客户集中和一次性因素。
净利率判断经营杠杆和费用压力。收入增长但净利率下滑，通常要打折。
经营现金流验证利润质量和回款。利润好但现金流差，要看应收、存货、客户账期。
ROE/ROIC验证资产效率。重资产低ROIC会限制财务质量上限。

8. 产业链利润池分

产业链利润池分 = 需求强度 × 稀缺性 × 涨价能力 × 成本转嫁能力 × 客户分散度

上游稀缺材料、卡脖子核心环节、海外对标清晰、进入放量或利润兑现、且有“我有你没有”财务验证，可以加战略溢价。下游组装、低毛利、客户议价强、概念映射无收入验证，要降权。

9. 其他修正模块

修正项核心逻辑硬规则
母子穿透母公司综合暴露 = 自有主业价值 + 子公司股权价值 + 产业协同价值 - 控股折价；子公司综合暴露 = 纯业务弹性 - 客户集中 - 产能爬坡 - 估值透支。母公司持股超过50%且有上游资产时，不默认子公司更好。
预期差/已定价看T-5到T、T到T+3、T到T+10是否继续跑赢。好结果不等于好买点。
客户集中最大客户>30%竞争力置信度封顶0.80；>40%封顶0.70；前五客户>60%财务质量封顶0.80。没有多客户放量验证，不能默认核心持仓。
二阶增长本期利润增速 - 上期利润增速，或本期利润增速 - 最近4季度平均利润增速。增长转负降低财务质量和趋势。
相对强弱RS_20 = 个股20日收益 - 主题篮子20日收益；Pair_RS = 目标股区间收益 - 替代股区间收益。基本面强但RS持续弱，要查隐藏问题。
V2.3.1铁律：同题材必须横向比较；每家公司都要回答是否卡脖子、替代到了哪个阶段、竞争对手是谁、“我有你没有/你有我更强/我弱于你”是什么；评分不等于仓位，最坏情景和组合暴露才决定仓位。

点火1.2 题材雷达

定位判断叙事是否处于首爆、扩散、明牌、总龙头模式或退潮。它是主题交易框架，不等于基本面持仓框架。

1. 叙事等级

等级类型特征明牌处理
C级事件型小题材单一新闻、单一公司、扩散弱。强惩罚，通常不追。
B级板块型短题材有板块联动，持续2-5天。明显降权，只做分歧低吸。
A级产业型大题材产业链长、分支多、可跨市场扩散。明牌不一刀切，看龙头地位。
S级时代型重估技术范式变化，市场持续寻找代表资产。允许总龙头模式切换。

2. NSS叙事强度

NSS = 产业空间20% + 技术范式变化20% + 政策/巨头催化15% + 产业链扩散宽度15% + 跨市场传播能力10% + 媒体解释密度10% + 连续催化能力10%
NSS等级处理
>=80S级允许总龙头模式。
65-79A级明牌龙头可观察，优先找滞后扩散。
50-64B级明牌明显降权。
<50C级明牌强惩罚或回避。

3. FID / PLS / ENOS

FID 首爆分 = 成交量爆发25% + 涨幅强度20% + 收盘强度15% + 低位/首日属性15% + 叙事新鲜度15% + 板块联动10%
PLS 正宗滞后分 = 映射正宗度30% + 未定价程度25% + 标签稀缺度20% + 跨市场传播潜力15% + 流动性可交易性10%
ENOS 早期叙事机会分 = 首爆强度25% + 正宗映射25% + 未定价程度20% + 传播路径确定性15% + 交易结构健康10% + 时间窗口奖金5% - 风险惩罚
分数找什么候选角色错误用法
FID第一个点燃题材、成交和涨幅最能带动扩散的股票或锚资产。首爆龙头、分支龙头、题材温度计。把首爆强度当成低风险买点。
PLS业务映射更正宗但涨幅未充分体现的公司。正宗滞后、待涨候选。只看正宗，不看未定价和流动性。
ENOS首爆后仍未明牌、传播路径清晰、交易结构健康的早期机会。早期叙事机会、低位补涨。在明牌高潮后继续按早期机会处理。

4. TLR / TLM 总龙头模式

TLR = 第一股/唯一股标签20% + 业务正宗度20% + 资产稀缺性15% + 股价反身性15% + 连续新催化10% + 板块带动能力10% + 跨市场锚定能力10%
TLM = 龙头地位25% + 叙事强度20% + 承接质量20% + 板块扩散15% + 新催化持续性10% + 换手健康度10% - 高位退潮风险
条件模式动作
NSS>=75 且 TLR>=80TLM总龙头模式用龙头判断题材温度，只在分歧承接强、小仓位时考虑，不追高。
TLR 65-79强势分支龙头降级观察，只做分歧支撑。
TLR 50-64强势跟风明牌惩罚。
TLR<50普通明牌强惩罚或回避。

5. 明牌分类与惩罚

类型特征处理
普通明牌大家都知道，但关联弱或只是跟风。强惩罚。
强势分支龙头分支正宗，但不是唯一叙事锚。降级观察。
叙事总龙头第一、唯一、正宗、稀缺，能反身性强化叙事。切到TLM。

6. 点火找核心受益公司的方法

  1. 先给叙事命名，不能只列股票。
  2. 判断NSS等级，决定它只是短题材，还是产业大题材/时代重估。
  3. 找FID：谁最先爆、最能带动板块。
  4. 识别明牌状态：普通明牌、分支龙头、总龙头、明牌高潮。
  5. 如果未明牌且FID强，找ENOS早期机会；如果已明牌，先算TLR/TLM。
  6. 扫描PLS：业务正宗、未充分定价、标签稀缺、可交易性足的滞后标的。
  7. 扫描跨市场接力：A/H/US之间是否存在时间差、估值差、情绪差。
  8. 扫描低位补涨：产业链扩散到分支环节，但必须有真实映射和流动性。
  9. 给每个候选标角色：首爆龙头、正宗滞后、跨市场接力、低位补涨、分支龙头、叙事总龙头、退潮锚。
  10. 最后明确交易纪律：总龙头不是追高许可证；后排掉队就要降温。

S五维量化减法

定位从数据底稿出发做减法，不从叙事偏好出发。先建完整公司池和赛道图，再用最近季度数据筛掉“故事好但经营世界不支持”的公司。

1. 五个维度

维度核心指标作用
成长性营收增长、利润增长。判断企业是否还在长大，偏好持续增长而非单季低基数爆发。
盈利性毛利率、净利率。识别价格权、高价值链位置和收入转利润能力。
经营规模营收规模、净利润规模。过滤没有真实利润池的故事。
资产效率ROE，必要时ROIC。判断是否靠资产高效赚钱，而非重资产扩张堆规模。
估值空间市值、PE.ttm、横向重估空间。只做讨论，不进入默认分数；问能否从小主题股被重估为平台型科技资产。

2. 默认季度优先评分

指标权重角色
营业收入同比增长率25%硬科技订单获取和交付的最早信号。
净利润同比增长率20%利润释放信号，必须结合毛利/净利避免低基数误判。
毛利率22.5%价格权和技术壁垒信号。
净利率22.5%收入转利润能力。
营收规模3%低权重规模校验。
净利润规模3%低权重利润规模校验。
ROE4%低权重资产效率校验。
市值规模0%展示为市场快照，不默认计分。
PE.ttm0%展示为市场快照，不默认计分。
关键点：核心四指标占90%，估值不用于默认排名。A股系统性高估要单独讨论，不把它机械判为个股贵。

3. 数据底稿流程

  1. 提取全部细分赛道、资金流向环节和上市公司。
  2. 去重，并区分A股、H股、海外股票。
  3. 标注纯正受益、相邻受益、宽口径映射。
  4. 保留原始细分赛道标签；多赛道公司可重复映射或指定主赛道。
  5. 拉取近9年年报数据作为长周期背景。
  6. 拉取最近6个季度数据，最好补足去年同期以计算单季度同比。
  7. 字段包括收入、净利、营收同比、净利同比、毛利率、净利率、ROE、市值、PE.ttm。
  8. 检查ST、退市风险、审计意见、监管处罚、会计问题。
  9. 市场快照必须标日期；确认PE是真TTM而非动态PE或静态PE。

4. Excel工作簿逻辑

页签内容目的
00_说明数据源、更新日期、指标定义、阈值、局限。让模型可复用、可审计。
01_公司池赛道、公司、代码、映射纯度、备注。保留全量底稿，不偷删。
02_年报9年原始数据公司、赛道、年度、九项指标。长周期背景，不进入默认评分。
03_最近6季度PK所有A股公司最近6季度比较。排在年度前，因为硬科技变化先出现在季度收入。
04_年度指标PK按成长、盈利、规模、效率、估值分组。背景验证，保留子分类和完整赛道。
08_赛道数据对比优先级表+赛道卡片。做决策页，不做宽表垃圾堆。
06_结论清单保留、观察、剔除，附原因。最终减法结果。

5. 减法规则

标签判定动作
High priority最新季度分数强，营收增长、利润增长、毛利率、净利率形成真实组合。核心跟进，但仍看估值和触发。
Watch一两个核心指标强，但另一个不稳定，如收入强净利弱。观察，等待缺口补齐。
Subtract营收增长弱、净利率为负、项目周期波动、ST/监管/审计风险，或数据无法证明收入转利润。减法，通常剔除。

6. 估值重估逻辑

估值不是“便宜/贵”的静态检查，而是重估空间问题。问四个问题：

  • 是否有国内或国际相似科技链龙头设定更高估值天花板？
  • 公司能否从小材料/军工/零部件供应商，被重新认知为核心芯片、技术平台、数据服务、定位技术或防务电子平台？
  • 市值是否仍低于可比龙头，同时成长、盈利、ROE在改善？
  • 估值模板是否被纯度弱、亏损、ST、会计可信度、一锤子订单破坏？

7. 赛道层面减法

优先留下小而关键、认证壁垒强、高毛利、可重复赚钱的环节，例如核心芯片、T/R模块、高可靠电子、功率器件、连接器、特种材料、核心定位模块。谨慎对待重资产、长周期、低毛利环节，例如发射服务、卫星平台总装、项目制地面基础设施、通用终端、早期概念映射。

8. 公司层面减法

每个保留赛道至少建立三桶：最值得留下的公司、领域龙头公司、被淘汰公司。比较九项指标，并解释为什么留下者至少赢在两三个维度；为什么接近的同行只是观察或减法；为什么财务排名高但治理/可信度有问题的公司要剔除。

S40 科技成长版

定位S40科技成长版是S老师原始40条的科技股改造版本。它不是机械阈值，而是多层验证漏斗。

真赛道天花板 + 真卡位/国产替代 + 真技术 + 真客户 + 真财务 + 真竞对/护城河 + 真龙头 + 真估值 + 真能力圈

1. 必走流程

  1. 确认公司、代码、板块、主营业务所在的细分赛道，不能只按大主题。
  2. 用最新年报、季报、公告、交易所文件、公司披露、可靠行情数据验证当前事实。
  3. 先测算主营细分赛道规模，分为百亿级、千亿级、万亿级。
  4. 判断增长来源：价格周期、量扩张、国产替代、新应用创造。
  5. 判断竞争格局：海外寡头、国产龙头集中、分散价格战、客户认证粘性、快速商品化。
  6. 明确是否真卡脖子：受限产品、海外巨头、国产替代、国产化率、客户验证、替代是否紧急且赚钱。
  7. 比较直接竞争对手：我有你没有、你有我更强、对手比我强。
  8. 把每条S40判断为适用、改造适用、仅参考/不适用。
  9. 分清事实和推断，低置信技术主张必须标注。
  10. 输出可纳入观察、继续跟踪、暂不买、只等触发或淘汰。

2. 真赛道天花板

检查项科技股改造口径结论影响
细分赛道使用最细可用赛道，不说泛泛的AI、机器人、半导体。赛道说不细，不能重仓。
天花板百亿级、千亿级、万亿级，结合TAM/SAM和渗透路径。百亿级也可优秀，但缺少外延时结论封顶观察。
增速近期和3-5年CAGR，区分价格周期和结构成长。结构性量增优于价格周期。
竞争格局海外寡头、国产集中、价格战、客户认证粘性、商品化。偏好大/中大市场、集中度改善、高切换成本。
政策政策方向必须转化为需求和订单。政策支持不能替代财务验证。

3. 真技术

  • 创始人/技术带头人：技术背景、产业资源、战略一致性、治理风险。
  • 核心团队：研发连续性、交付能力、关键人员稳定性。
  • 市场份额：用细分产品份额、国产替代位置、装机基础、核心产品出货排名。
  • 替代路径：替代进口设备/材料/软件/芯片/模块、海外供应商、人工流程或旧国产产品。
  • 护城河证据：客户、设计定点、认证、订单、出货、良率、性能、进口份额下降。
  • R&D比例：10%只是底线，不是通过证；还要看绝对研发金额、人员、专利、路线和产品收入转化。

4. 真财务：传统S40阈值的改造

原始指标科技成长改造
市值>1000亿用于流动性和稳定性，但不能排除早期龙头；小市值需更强证据和更严风控。
上市>5年不硬排科创/创业板新公司，但要看多个报告期、IPO问询、上市后交付一致性。
主营>60%非常重要。蹭题材而收入不支撑，直接降级。
毛利率>30%不能统一套，必须同赛道横比和看趋势。
净利率>10%高研发公司可暂不达标，但要看费用杠杆和盈利路径。
EPS>0.3对亏损早期科技不适用，改看收入质量、毛利、订单、现金消耗、盈利时间表。
ROE>15%成熟科技应接近；早期看ROIC趋势、资产周转、单位经济。
净利增长>20%盈利公司适用；未盈利公司改看收入、毛利、订单增长和亏损收窄。
经营现金流为正成熟公司应通过；早期公司看现金消耗、应收、账期、融资跑道。
PE<20不作为科技股通用买点，只适用于成熟科技价值检查。
分红/送转成熟公司加分；成长公司不因再投资而扣重分。

5. 真龙头与竞对

必须在正确细分赛道内比较，不能按宽泛科技板块排名。比较项包括产品范围、性能/良率/可靠性、客户资质、成本/规模、交付能力、毛利率、现金流和资产负债表韧性。

6. 真估值

公司类型估值方法
成熟盈利科技PE、PEG、EV/EBITDA、ROE/ROIC。
SaaS/软件/数据/AI应用PS、EV/Sales、ARR倍数、留存、毛利、CAC回收。
半导体设备/材料/器件PE/PS、订单、capex周期、国产化率、库存周期、客户认证。
机器人/低空/商业航天情景估值、订单验证、交付节点、现金消耗、政策到需求转换。
亏损公司收入质量、毛利、现金跑道、稀释风险、盈亏平衡路径、情景概率。
静态安全边际 = (历史最低估值 + 历史平均估值) / 2 动态安全边际 = 静态安全边际 × (1 + 保守增长率)

7. 真能力圈

如果分析者不能讲清产品、技术路线、为什么重要、怎么赚钱、客户是谁、竞争对手是谁、替代谁、护城河是什么、增长为什么能持续、该用什么估值、什么会证伪，就要判定“不在能力圈内，暂不买/只观察”。

8. 硬淘汰信号

  • 核心技术收入未披露或占比很小。
  • 核心逻辑主要依赖题材语言。
  • 主营细分赛道无法测算，或只是百亿级弱增长却要求顶级成长估值。
  • 国产替代说不清受限产品、海外巨头、替代证据和客户验证。
  • 护城河不能表达成“我有你没有”或“你有我更强”。
  • 现金跑道弱，融资风险高。
  • 应收/存货恶化快于收入。
  • 客户极度集中且无长期稳定合约。
  • 估值要求不现实增长。
  • 技术和商业模式讲不清楚。

边界与禁区

不能混用的点：点火强不等于基本面强；S五维高不等于当下能买；S40通过不等于短线有买点；V2.3.1评分不等于仓位。

不能省略的点：当前行情/公告/财务必须现查；官方公告优先于媒体；累计财务要拆单季；数据缺口要明说；非交易日和主要数据缺失时只能出观察版。

不能假装确定：没有订单、客户认证、收入拆分和利润转化的业务，只能按能力证据或未来期权处理，不能当当前业绩锚。

最稳的组合方式：点火给方向和角色，V2.3.1给同题材择优，S五维给数据减法，S40给科技成长终审。四套框架各司其职，结论才不会被题材热度带跑。
