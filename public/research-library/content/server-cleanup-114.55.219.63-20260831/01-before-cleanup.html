操作前必须遵守的停止条件

  • 如果目标容器不是 exited，停止并重新评估，不能删除或搬移其日志。
  • 如果有真实进行中的 Docker build，跳过缓存清理，等待构建结束。
  • 如果 /data2 可用空间不足以容纳归档，不能跨盘搬移旧日志。
  • 如果 Nginx 配置测试不通过，不能执行日志 reopen 或强制轮转。
  • 如果日志文件仍被 Java/Nginx 打开，不能直接 gzip、rm 或 rename，必须使用对应的安全轮转方式。
