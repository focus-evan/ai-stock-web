S老师的投研不是从股票代码开始，而是从一个可决策的大问题开始：先恢复产业全景，再逐级缩小范围，最后让极少数资产接受公司、财务、估值和风险的连续审讯。

投研的目的

不是证明一个观点很聪明，而是决定：买入、观察还是淘汰；如果观察，观察什么；如果买入，凭什么、以什么价格和多大仓位。

01 · CORE MODEL

投研不是搜资料，是做决策

“资料多”不等于“研究深”。他的标准是：信息是否进入结构、变量是否能验证、风险是否能证伪、结论是否能落成动作。

A / DIRECTION

先找时代方向

宏观、政策、技术革命和产业资本开支共同决定“时间应该花在哪里”。宏观不负责精确择时，而负责筛选主航道。

B / STRUCTURE

再还原产业结构

把需求、供给、政策、技术路线、竞争者、上中下游和价值量画出来。产业链是信息的抽屉，也是后续做减法的底图。

C / EVIDENCE

让公司和财务验证

公司能否吃到产业红利，要由团队、研发、份额、客户、订单、毛利、现金流和资产负债表共同回答。

“没有全局的情况下，看到的所有都是离散的斑点。只有看到全局，才知道哪些细节能够帮助决策。” 黄埔22期06天上午，转写行11761–11767；直接课程语料

02 · METHOD TOOLBOX

他不是只有一个框架，而是一套投研工具箱

kd_demo中的黄埔01阶课程明确把产业知识与投研方法“双线教学”。不同赛道调用不同工具，必要时多种方法交叉使用。

方法适用场景核心问题
历史投研法平台、产业演进、国家竞争今天的格局是怎样一步步形成的？过去的胜负因素还成立吗？
全景政策投研法医药等强政策行业把多年政策串成时间线与分类图，政策意志最终指向哪里？
由上而下赛道法一级赛道包含大量异质细分哪些共享逻辑先决定大部分细分赛道的命运？
新物种问题模型新事物替代旧事物能否成趋势、凭什么替代、何时跨过商业化临界点、谁会受益？
标杆企业投研法判断技术上限与竞争C位最领先企业已经走到哪里？行业平均值是否掩盖真实前沿？
科普投研法硬科技与陌生术语先消除认知障碍，再删繁就简，只留下会影响投资判断的知识。
棋盘思维横向竞争、平台生态参与者、位置、进攻路径和相互制约如何变化？
四维博弈法竞争激烈、上下游复杂横向竞对、纵向上下游、替代路线与资本/政策如何共同分配利润？
产业链层级法机器人、AI硬件等复杂链条先一级结构，再二级结构，再按价值量、壁垒和数据做减法。
财报验证法产业逻辑进入兑现期订单、收入、利润、现金流是否验证了原先的产业假设？
高质量学习闭环：每研究一家企业，关闭资料，用5–8分钟按“赛道 → 公司基本面 → 估值”重新讲一遍。讲不清楚，说明尚未内化；同一赛道第一年打底，第二年以后主要做更新。

03 · WORKFLOW

九步产业投研闭环

这九步综合了课程转写、澜起/绿的谐波投研模板，以及宇树、寒武纪、江波龙等对话中的真实研究过程。

定义决策型大问题

避免“介绍一下公司”。问题必须指向决策或冲突，例如“追高后多久回血”“800亿配售意味着什么”“估值是否已透支未来增长”。

产出：一句话研究命题、决策对象、截止时间与需要回答的动作。

建立事实底稿

阅读现有文献，先做原汁原味的小结；标明发布日期、数据口径、原始来源和未覆盖问题。资料不足时再扩大检索。

产出：事实表、数据钉子、来源清单、未知项。

画产业全景

定义产品和细分赛道，拆上游/中游/下游、技术路线、需求场景、供给约束、政策与资本开支，把事件放入产业阶段。

产出：产业树、价值链、阶段判断、关键传导链。

做赛道层加法

把所有可能受益环节、替代路径、竞争维度和风险列全；不急着押注，先确保没有因视野狭窄漏掉关键变量。

产出：细分赛道候选池与完整问题树。

先从赛道做减法

比较规模、增速、天花板、景气持续性、利润池、竞争强度、壁垒、国产化/渗透率和估值，把低质量或低弹性赛道先砍掉。

产出：优先赛道、观察赛道、淘汰赛道及理由。

再做公司层减法

比较团队、研发、产品、客户、份额、标准权、议价权、商业模式、并购与治理；判断是“人无我有”还是仅仅跟随景气。

产出：同赛道公司PK、护城河判断、幸存者清单。

财务重构因果链

不只看利润增速。把收入、毛利、库存、预付款、合同负债、应收、现金流、减值和交付节奏串起来，判断增长来自需求、供给、价格还是确认节奏。

产出：财务诊断、异常解释、产业逻辑验证/证伪。

估值与情景推演

测算当前价格隐含的收入、利润和增长年限；设乐观、中性、悲观三种情景，列催化剂、风险、时间和可证伪条件。

产出：预期差、回报起点、关键风险与触发器。

给动作并建立监控

必须明确买入/观察/淘汰。观察要有变量，买入要有价格、仓位和前提；财报和行业数据用于持续验证，而非事后追涨。

产出：决策卡、监控清单、下一次复核时间。
AI辅助的正确姿势：AI先生成结构化初筛报告，人仍然是BOSS。读完报告后抓重点、列出未回答的问题、调用更多资料或工具补齐，直到形成闭环；不能把“5秒生成报告”误当作“研究已经完成”。

04 · ADD / SUBTRACT

“先加法，再减法”的准确含义

这里的加法不是多买股票，减法也不是简单少买。它们发生在不同阶段，服务于“先保证不漏，再保证不乱”。

阶段要做什么为什么常见错误
认知加法还原产业全貌、变量、环节、技术路线、竞争者和情景避免被明星公司或单篇文章锁死视角一上来就问“买哪只”
赛道减法用成长、利润池、竞争、壁垒、景气持续性与估值砍掉细分赛道个人资金和精力有限，先决定“哪里值得研究”每个环节都觉得有机会
公司减法用团队、研发、份额、客户、财务和治理淘汰公司赛道β不保证每家公司都有α把景气度当成公司护城河
深度加法对少数幸存者补齐财报原文、竞争证据、订单、估值和风险只有少数资产值得投入重度研究减完就直接下单，没有再验证
组合减法按能力圈、资金体量和底层相关性再砍一轮看到全貌不等于按全貌配置同一逻辑持有很多公司，形成伪分散
“投资首先是做大量的减法，才会真正值得再去做加法：把时间、精力和真金白银聚焦到极少量好赛道里的优秀资产，还得是好价格。” 黄埔22期05天晚上，转写行9619；直接课程语料
一个重要细节：减法后仍需加法。课程明确指出，筛掉大部分资产后，不能只盯“不达标项”，还要为准备投资的少数候选补充定性和定量证据，证明“为什么值得投”。

05 · QUESTION TREE

可直接复用的问题清单

问题的次序很重要：先赛道，后公司，再估值和风险。每个答案最好同时包含事实、推理、结论和仍待验证项。

赛道面：值不值得花时间

  • 产品到底解决什么问题？属于哪个细分赛道？
  • 市场规模、增速、天花板分别是多少？口径是什么？
  • 需求、供给、政策三端的成长逻辑是什么？
  • 当前处在萌芽、验证、扩张、成熟还是出清阶段？
  • 技术路线有哪些？胜负依据和切换风险是什么？
  • 竞争格局、关键竞争要素和利润池在哪里？
  • 周期驱动因素是什么？景气能持续多久？
  • 哪些环节价值量大、壁垒高、弹性强且替代刚开始？

公司面：谁能真正吃到

  • 创始人、核心团队与战略执行历史如何？
  • 研发费用、研发人数和产品迭代是否匹配赛道难度？
  • 市场份额、主要客户、客户集中度和议价权如何？
  • 与全球/国内核心对手相比，优劣势是什么？
  • 壁垒是技术、标准、生态、成本、渠道还是专有资源？
  • 商业模式是否可复制？规模扩大后利润是否改善？
  • 治理、股权、国资、并购和关联交易有哪些影响？
  • 财务数据里有哪些异常或与叙事不一致的地方？

财务面：增长到底从哪里来

  • 收入增长来自销量、价格、并表还是一次性因素？
  • 毛利和净利变化与产业逻辑是否一致？
  • 库存、预付款与委托加工说明备货还是积压？
  • 合同负债、应收和现金流能否支持真实需求？
  • 供应链瓶颈还是需求不足导致交付节奏变化？
  • 减值、非经常损益和会计确认是否扭曲利润？

估值与决策：价格隐含了什么

  • 当前PE、PS、市值和动态安全边际如何？
  • 当前价格透支了多少年收入与利润增长？
  • 估值框架由什么决定？何时可能切换？
  • 乐观/中性/悲观情景的关键假设是什么？
  • 哪些催化剂提前兑现？哪些风险推迟兑现？
  • 最终是买入、观察还是淘汰？观察哪个变量？

07 · QUALITY GATES

怎样才算“投研做得好”

不是字数长，也不是结论强，而是以下质量门同时成立。

  • 事实、推理、判断和建议分开写
  • 关键数字有原始来源、日期和口径
  • 结论能被至少一个反向证据证伪
  • 先说明产业阶段，再解释公司表现
  • 既看增长，也看增长质量与现金流
  • 写清未覆盖问题与信息缺口
  • 观察结论必须对应具体监控指标
  • 财报用于验证预测，不重写历史逻辑
  • 配置与仓位服从能力圈和资金属性
  • 最终结论能转成下一步行动
