S-CREATOR · SKILL LOGIC

从全民热搜，
走到财富底层。

不只找财经新闻。先抓全天最热事件，再用事实核验、财富翻译和产业框架，把“围观”变成可复用的财商能力。

一句话逻辑 热度负责让人停下，财富结构负责让人留下，方法负责让人学会。

01 · CORE PIPELINE

六步生产闭环

从“全网发生了什么”开始，到“用户学会了什么”结束。新闻只是入口，能力才是交付。

1全网选题

社会、娱乐、体育、科技、互联网、国际、商业与财经。

2事实核验

至少两源；一手或权威来源确认关键事实。

3财富翻译

谁创造价值？谁控制分配？谁拿钱？谁担风险？

4路径选择

A股/产业、商业/财富，或两者结合的混合路径。

5脚本成稿

虎头 + Part01 + Part02 + Part03，5–6分钟。

6校验发布

长度、金句、来源、事实边界、去重与飞书发布。

02 · NEWS UNIVERSE

选题不设财经边界

进入候选池靠真实热度，进入成稿靠财富解释。纯猎奇、纯站队和无证据传闻会被过滤。

热
真实公共热度跨平台讨论，不是单个账号自说自话。
真
事实可以核验当事人、机构、法院、警方、政府、平台或正式公告。
财
财富结构可解释至少讲清价值、所有权、现金、信用、激励或风险之一。
用
观众能带走方法看完能执行一个检查动作，而不是只记住八卦。

03 · ROUTING

三条解读路径

先选路径，再写内容。没有自然A股关系时，宁可讲透财富结构，也不硬凑概念股。

A股 / 产业路径

适合公司、政策、产品、供需、行业与资产价格事件。

  • 讲清订单 → 收入 → 毛利 → 现金 → 估值。
  • 区分直接相关、间接相关与概念关联。
  • 给出观察指标和失效条件，不给一刀切买卖指令。
最终让股民知道：这条新闻如何进入自己的持仓和观察池。

商业 / 财富路径

适合社会、娱乐、体育、互联网、公众人物和平台事件。

  • 拆注意力、信誉、所有权、合同、平台和现金流。
  • 只谈可核验行为，不猜私交、动机或利益输送。
  • 落到普通人的财商动作：核验交易对手、区分账面财富与现金。
最终让用户知道：热搜背后，财富和风险究竟如何分配。

混合路径

适合公众事件同时影响品牌、平台、监管、产业链或资产价格。

  • 先讲公共事件里的财富结构。
  • 再讲能够被公告、合同、订单或财务验证的市场映射。
  • 热度与股价相关，不等于热度创造了公司利润。
最终把全民讨论与资本市场连接起来，但连接必须可验证。

05 · WEALTH LENSES

八个财富底层镜头

每篇只选最相关的2–4个。目标不是概念堆砌，而是回答“钱和权如何流动”。

◇

价值创造

产品、服务、技术、内容或稀缺资源，谁让用户愿意付钱？

⌂

所有权与控制

品牌、账号、版权、数据、渠道、股权和决策权归谁？

↗

收入与现金流

谁付钱、谁抽成、谁先拿现金、谁承担库存与尾部损失？

◎

注意力经济

谁拥有分发权？热搜能否沉淀成成交、复购和品牌资产？

♢

信誉与关系资本

公开互动只是一种信号；信用仍需合同、资产和履约证明。

⚖

激励与博弈

平台、品牌、资本、粉丝和当事人，目标是否一致？

≈

杠杆与流动性

名义财富能否变现？是否集中在单一资产、平台或关系上？

?

信息与风险定价

谁掌握原始信息？普通人应为不确定性预留多少安全边际？

06 · SCRIPT

5–6分钟固定脚本

1600–2100个中文字符。每30–45秒跨一个认知台阶，至少2句原创金句。

00:00

爆款虎头

大众事实 + 财富暗线 + 方法承诺。

80–180字
PART 01

热点真相

事实与推测分开；150字内回答为什么与钱有关。

400–550字
PART 02

财富 / 产业拆解

谁创造、谁控制、谁拿钱、谁担风险；需要时加入A股传导。

550–750字
PART 03

普通人怎么学

行动方法、观察信号、失效条件，以及自然的学习承接。

450–650字

07 · QUALITY GATES

发布前的红绿灯

热度不够可以不写，事实不清必须不写。每篇都要先过内容闸门，再过格式校验。

可以写

  • 跨平台真实热度
  • 至少两源、一手可核验
  • 能交付财富或投研方法

谨慎写

  • 关系、取关、互动只是信号
  • 热度与利润传导尚需验证
  • 账面估值与现金必须分开

不能写

  • 未经证实的私生活或违法指控
  • 硬凑概念股、承诺收益
  • 只有猎奇，没有财富结构

THE LEARNING LOOP

热点每天变，财富结构可以重复使用。

最终目的不是告诉用户“今天该买什么”，而是让用户持续跟随S老师，学会拆商业模式、资本关系、现金流、信用与风险。
