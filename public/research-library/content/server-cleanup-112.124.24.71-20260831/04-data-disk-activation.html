步骤2：空盘保护性复核

所有输出必须证明 /dev/vdb 是256 GiB空盘
lsblk -b -o NAME,PATH,SIZE,TYPE,FSTYPE,UUID,MOUNTPOINTS,SERIAL /dev/vdb
wipefs -n /dev/vdb
blkid /dev/vdb || true
file -s /dev/vdb
parted -s /dev/vdb unit s print
  • 序列号必须是 bp11pv1avns1aa578cs6。
  • 容量必须是 274877906944 bytes。
  • 不得存在子分区、文件系统签名、UUID或挂载点。
  • 任何一项不符都必须停止，不能格式化。

步骤3：创建GPT分区和ext4

此步骤会写入 /dev/vdb，仅适用于已确认空盘
disk_device=/dev/vdb
partition_device=/dev/vdb1

test "$(lsblk -dn -o SERIAL "$disk_device" | xargs)" = bp11pv1avns1aa578cs6
test "$(lsblk -bdn -o SIZE "$disk_device" | xargs)" = 274877906944
test -z "$(wipefs -n "$disk_device" 2>/dev/null || true)"

parted -s "$disk_device" mklabel gpt
parted -s "$disk_device" mkpart primary ext4 0% 100%
partprobe "$disk_device"
udevadm settle
test -b "$partition_device"

mkfs.ext4 -F -L data2 "$partition_device"
e2fsck -fn "$partition_device"

首次安全校验曾因容量命令返回人类可读的“256G”而在写盘前停止；改用 lsblk -b 字节模式后才继续。

步骤4：挂载、fstab和可写验证

挂载到全新空目录 /data2
audit_dir=/var/backups/server-cleanup-112.124.24.71-20260831-1150
cp -a /etc/fstab "$audit_dir/fstab.before-data2"
mkdir -m 0755 /data2

data_uuid="$(blkid -s UUID -o value /dev/vdb1)"
printf 'UUID=%s /data2 ext4 defaults,nofail 0 2\n' "$data_uuid" >> /etc/fstab
systemctl daemon-reload
mount /data2

mountpoint -q /data2
test "$(findmnt -n -o SOURCE /data2)" = /dev/vdb1
touch /data2/.write-test
sync
rm -f /data2/.write-test
findmnt /data2
df -hT /data2

随后实际执行过一次卸载和 mount -a 重挂载测试，证明开机配置有效。

步骤6：Dify PostgreSQL在线备份

使用CUSTOM格式、临时文件原子改名、SHA-256和35天保留策略。

安装并执行

install -m 0755 /tmp/bzsj-dify-postgres-backup.sh \
  /usr/local/sbin/bzsj-dify-postgres-backup.sh
