一整套可执行交易策略

1. 开仓前过滤

  1. 只看“推荐”和“强烈推荐”，优先强烈推荐。
  2. 核心启用战法优先级最高：北向资金、事件驱动。
  3. 大盘弱、主线退潮、跌停扩散时，只允许北向轻仓或空仓。
  4. 同一股票被多个正向战法同时选中时，才允许提高仓位。

2. 仓位结构

  1. 常态总仓位不超过 50%，强赚钱效应可到 70%。
  2. 核心战法占 50%，条件启用占 35%，快打战术不超过 15%。
  3. 单票上限：强烈推荐 8%，推荐 5%，低流动性股票再减半。
  4. 同一题材最多 3 只，避免看似分散、实际同涨同跌。

3. 买入纪律

  1. 回测统一按推荐日收盘买入，实盘不追高超过推荐价 3%。
  2. 北向/事件允许分两笔，第一笔收盘，第二笔次日确认承接。
  3. 龙头/接力只在情绪上升和板块强度确认时买。
  4. 隔夜/竞价只做尾盘或次日确定性，不把短线单做成长线。

4. 卖出纪律

  1. 隔夜和竞价：次日冲高优先卖，均价不占优时不能等收盘。
  2. 事件驱动：T+3 到 T+5 兑现，利好落地或放量滞涨先减半。
  3. 北向资金：T+10 到 T+15 兑现，跌破入场价或资金逻辑断开退出。
  4. 龙头/接力：T+1 到 T+3 分批卖，断板弱修复失败立即退出。

5. 止损规则

  1. 快打战术单笔止损 -2.5% 到 -3%。
  2. 事件/量价/突破单笔止损 -4% 到 -5%。
  3. 北向/趋势类单笔止损 -6%，但若逻辑失效不等止损价。
  4. 组合从高点回撤超过 8%，总仓位降到 20% 以下。

6. 每日复盘

  1. 收盘后记录：战法、推荐级别、买入价、卖出价、是否按纪律执行。
  2. 每周更新各战法胜率和平均收益，连续 20 笔低于 0 的战法降权。
  3. 只复盘“按纪律交易”的样本，违规交易单独统计。
  4. 每月重算策略权重，核心战法必须同时满足正收益和可控回撤。
