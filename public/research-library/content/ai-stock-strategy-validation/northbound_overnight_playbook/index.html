北向资金：可跟投执行规则

可以买的条件
  1. 系统给出北向资金推荐或强烈推荐。
  2. 优先强烈推荐，普通推荐只做半仓。
  3. 推荐股不是连续大涨后的高位加速。
  4. 大盘不处在连续放量下跌或系统性风险日。
买入方式
  1. 若信号在盘中出现，14:40-14:55 靠近收盘价分批买。
  2. 若盘后才看到，次日不追高；高开超过 2.5% 先等回踩。
  3. 强烈推荐单票 6%-8% 上限；推荐单票 3%-5% 上限。
  4. 同一行业最多两只，避免伪分散。
持有节奏
  1. T+3 只看承接，不急着卖。
  2. T+5 若收益超过 6%，先卖 1/3。
  3. T+10 若收益超过 10%，再卖 1/3。
  4. T+15 必须重新评估，没有新信号就退出剩余仓位。
必须止损
  1. 收盘亏损超过 4%，次日不能修复则减半。
  2. 收盘亏损超过 6%，直接清仓。
  3. 跌破入场逻辑对应的关键均线或资金逻辑失效，不等价格止损。
  4. 组合连续两笔北向亏损，下一笔仓位减半。
加仓规则
  1. 只有浮盈超过 3% 且回踩不破成本，才允许加仓。
  2. 加仓后单票总仓不超过 10%。
  3. 亏损不加仓，不做摊平。
  4. T+10 以后不加仓，只管理退出。
禁止动作
  1. 用北向资金做盘中秒级追涨。
  2. 因为“外资买”忽视个股放量滞涨。
  3. 把 T+15 失败单继续拖成长期持仓。
  4. 同一天买满多个高度相关的大盘白马。

隔夜战法：可跟投执行规则

可以买的条件
  1. 只做评分 90+ 或强烈推荐优先。
  2. 当日市场不能是明显退潮日。
  3. 个股尾盘不能放量跳水，不能收在日内低位。
  4. 单日最多 2-3 只，宁可错过，不做拥挤。
买入方式
  1. 14:45-14:57 买，不提前追。
  2. 买入价尽量贴近系统推荐价或当日收盘价。
  3. 强烈推荐单票不超过 2.5%；推荐不超过 1.5%。
  4. 隔夜总仓不超过 8%，强行情也不超过 12%。
次日卖出
  1. 高开 1%-3%，开盘 15 分钟内卖一半。
  2. 盘中冲到 +3%，卖到只剩观察仓。
  3. 冲到 +5% 以上，不贪，剩余仓位用分时跌破均线卖。
  4. 没有冲高但横盘走弱，10:30 前处理完。
止损规则
  1. 低开超过 1.5%，先不补仓，观察 15 分钟。
  2. 无法收回开盘价或昨日收盘价，直接卖。
  3. 浮亏达到 3%，无条件退出。
  4. 隔夜单绝不允许因为亏损变成北向/趋势单。
优先选择
  1. 评分 90+ 的样本表现明显更稳。
  2. 排名 4-5 的历史均价表现反而好于排名 1，排名 1 要防高位拥挤。
  3. 强烈推荐和推荐差别不大，卖出纪律比级别更重要。
  4. 连续退潮月份或近期隔夜胜率差时暂停。
禁止动作
  1. 次日已经给冲高仍然幻想涨停。
  2. 开盘低于预期还补仓。
  3. 把隔夜战法持有到第三天。
  4. 在大盘连续杀跌时做隔夜满仓。

组合执行：北向做主仓，隔夜做刀尖

默认资金分配
  • 北向资金：60%-75% 的策略资金。
  • 隔夜战法：5%-8% 的策略资金。
  • 现金：至少 20%，用来防回撤和等新信号。
强市场
  • 北向可提到 75%。
  • 隔夜可提到 10%-12%，但只做 90+ 评分。
  • 龙头/事件有共振时，优先给北向票加权。
弱市场
  • 北向降到 30%-40%。
  • 隔夜直接降到 0%-3%。
  • 连续两天组合亏损，第三天不开隔夜新仓。

每日跟投时间表

09:25-09:35只处理隔夜旧仓。高开卖、低开观察 15 分钟，不做临时加仓。
10:30 前隔夜旧仓必须基本处理完；没有冲高的弱票退出，不拖到下午。
14:20-14:40检查北向和隔夜新信号：只保留强烈推荐、评分高、形态没有明显破坏的候选。
14:45-14:57执行买入：北向按计划分批，隔夜只小仓；价格偏离推荐价过大则放弃。
收盘后记录每笔交易的策略、买卖原因、是否按纪律执行；违规单独统计，不混入策略胜率。
