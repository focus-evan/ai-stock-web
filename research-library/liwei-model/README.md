# 立伟每日研判

入口与「野人交易手册」并列，位于研究与知识库 → 抖音研究资料 → 立伟每日研判。
公开路径：`/research-library/content/douyin/liwei-model/index.html`。

每天北京时间 08:30 盘前、19:30 收盘后更新；休市日也记录风险检查。调度由既有 Codex 本地定时任务执行，依赖 Mac、Codex 和网络可用。页面显示报告时间与行情截止日，超过应更新时间 90 分钟后提示未更新。报告是公开语料重建模型的研究结论，不代表立伟本人观点。

价格侧代码在本目录 `engine.py`；通过 `LIWEI_MODEL_DIR` 指向持久研究目录运行。模型数据、94 条开发语料、质量标记和首期报告在 `public/research-library/content/douyin/liwei-model`。原版恐贪、底部和资金身份等未知模块不能由代理指标冒充，未验证收益。

## 生成与发布

1. 遵循研究目录的 RUNBOOK.txt，核实真实时间、交易日历和独立行情来源，更新 context 并生成不可覆盖的 daily 快照。
2. `python3 scripts/publish-liwei-model.py --source <研究目录> --export <预览目录>` 生成并检查公开页面。导出剔除本机路径、执行说明与部署代码；不改研究输入。
3. 先检查并提交代码，推送 origin/main；静态内容发布提交使用 `[skip ci]`，避免触发现有整站部署流程。发布器必须来自已推送的 main 提交。
4. `python3 scripts/publish-liwei-model.py --source <研究目录> --state <持久状态目录> --check` 按当前线上版本准备候选。
5. 加 `--activate <本次候选目录>` 发布该确切候选；不带 check/activate 则准备并发布。

独立发布器只修改立伟子目录、抖音门户的一个菜单入口及对应目录元数据。它保留线上其余文件、账号、方法手册、专题及历史报告；采用既有服务器锁、基线版本比较、硬链接快照和原子切换。源或线上改变就拒绝并重新准备。不执行应用部署、依赖安装、SQL、服务重启或清理。

公网报告、历史、JSON、目录、门户与野人手册须全部返回预期 SHA256，容器状态须未变。成功记录含代码提交号和回滚目录。主应用目录存在历史锁文件变更时，整站部署仍受阻；本发布仅使用独立 `/data/research-library-publisher` 内容服务。

23:00 抖音全量更新须在范围合并后调用 `preserve_liwei`，保留独立研判的目录项和并列菜单，避免原始账号目录重新生成时移除入口。该兼容步骤不生成新研判，也不改变其日期。
