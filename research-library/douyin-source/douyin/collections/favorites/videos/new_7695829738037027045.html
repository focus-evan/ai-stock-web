REA与Agent驱动的软件复刻流程

作者 阿东玩AI（练薄肌版）发布时间 2026-10-13 01:09:52aweme_id 7695829738037027045图文OCR完成 · 文案已复核

打开作者主页

重点摘要

  1. 作者介绍REA通过MCP连接逆向工具，让Claude Code、Codex等Agent分析二进制、Electron、APK和网站。
  2. 其组合方案用REA做证据化逆向、replica-skill串起11步复刻流程，并强调clean-room重建和只分析有权处理的软件。
  3. 作者认为代码壁垒下降后，业务理解、客户关系和服务能力更难复制。
整理后的文本
【发布正文】
agent克隆一切软件。阿东这两天在 GitHub 上看到 REA 火了，14 万星。它干的事很直接：让 Claude Code、Codex 这些 Agent 读懂没有源码的二进制，再把功能复刻出来。 过去四十年，软件价值一部分押在「源码不可得」上，REA 动摇的正是这个前提。 我自己试了下，最实用的组合是 REA + replica-skill + Claude Code/Codex——一个拆二进制，一个跑完从逆向到上线的 11 步流水线。 代码壁垒在快速下降，但业务理解、客户关系，才是真难复制的东西。 maybe后边去当销售、做硬件、搞营销，maybe。 阿东，大模型算法工程师，OPC创业者。 #rea #agent #github #agent #我要上热门🔥

我总结了一套工作流
看完REA的热度之后，我自己也去试了试，发现
单靠REA能把“看懂”这件事做得不错，但要从
看懂”一路做到“做出一个能用的项目”，还需
要再叠一层完整的复刻流水线。
目前我总结下来最实用的组合是：
REA + replica-skill + Claude Code /
Codex
REA负责深度逆向：没有源码也能拆二进制、
Electron、APK、网站等，输出带证据的分析结
果。
